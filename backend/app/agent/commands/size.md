# Command: /size

## Syntax

```
/size "<brand or condition>"
```

## Examples

```
/size "do Nike shoes run small?"
/size "I have wide feet, what should I get?"
/size "I'm between a 9 and 10 in Adidas"
/size "flat feet, need arch support"
```

## What It Does

Activates the **Size Expert Agent** which loads the `size-fitting` skill.

The agent gives specific, accurate sizing guidance — brand quirks, foot
conditions, between-sizes decisions — rather than generic "check the size guide" advice.

## Agent Loaded

→ `agents/size-expert-agent.md`

## Skills Loaded

→ `skills/size-fitting/SKILL.md`

## When to Use

Use `/size` when the customer:
- Asks if a brand runs true to size
- Mentions a foot condition (wide, flat, high arch, overpronation)
- Is between sizes and needs a recommendation
- Wants a size comparison between brands
