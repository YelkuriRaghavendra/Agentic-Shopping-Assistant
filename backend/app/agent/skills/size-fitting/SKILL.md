# Size Fitting Skill

## When to Apply This Skill

Apply when:
- Customer asks if a brand runs small or large
- Customer mentions a foot condition (wide, flat, high arch)
- Customer is between sizes
- Customer wants to compare sizing between brands
- Customer is unsure which size to order

## Foot Condition Guide

### Wide Feet

Recommended brands:
- **New Balance** — best wide range (2E, 4E widths)
- **Brooks** — naturally roomy toe box
- **ASICS Gel** — wider last available
- **Hoka** — inherently roomy toe box

Avoid narrow brands (or size up):
- Adidas, Saucony, Mizuno — size up half

### Flat Feet (Low Arch)

Need: **motion control** or **stability** shoes

Best options:
- Brooks Adrenaline GTS
- ASICS Gel-Kayano / GT series
- New Balance 860
- Saucony Guide

Avoid: neutral cushioned shoes (no support for collapsed arch)

### High Arch

Need: **neutral cushioning** with arch-neutral last

Best options:
- HOKA Clifton / Bondi
- Brooks Ghost
- New Balance Fresh Foam
- Nike React Infinity

Avoid: motion control or stability shoes (force the arch into unnatural position)

### Overpronation (Foot rolls inward)

Need: **stability** or **motion control** shoes

Best options:
- ASICS GT-2000 / Gel-Kayano
- Brooks Adrenaline GTS
- New Balance 860
- Saucony Guide

### Between Sizes

When customer is between sizes:

```
For running / athletic use:  → SIZE UP
  More toe room for foot swelling during exercise

For casual / lifestyle use:  → DEPENDS ON FIT PREFERENCE
  Slim fit preference → size down
  Comfort preference → size up

For formal / dress:  → SIZE DOWN
  Leather stretches slightly with wear
```

## Sizing Decision Tree

```
Customer asks about sizing
         │
         ├─ Has foot condition?
         │     ├─ Wide      → Recommend wide-fit brands, size up in narrow
         │     ├─ Flat      → Motion control shoes specifically
         │     ├─ High arch → Neutral cushioned shoes
         │     └─ Overpronate → Stability shoes
         │
         ├─ Between sizes?
         │     ├─ Athletic use  → Size up
         │     └─ Casual use    → Depends on fit preference
         │
         └─ Brand-specific question?
               └─ Use brand sizing reference table above
```

## Response Rules

1. **Give a specific recommendation** — not "it varies"
2. **Explain the reasoning** — "because Adidas runs narrow"
3. **End with the official size chart suggestion** — always
4. **One clear answer** — don't give three options for "which size"

## Response Template

```
1. State the brand's tendency
   "Adidas runs slightly narrow compared to other brands."

2. Apply to customer's situation
   "Since you have wide feet, I'd recommend going half a size up from your
   usual — if you're normally a 10, go with a 10.5 in Adidas."

3. Explain why
   "The Ultraboost especially has a snug toe box, so the extra room
   makes a real difference over longer distances."

4. Close with size chart
   "For your exact measurement, the Adidas size chart on their site is
   accurate — but the 10.5 is a solid starting point."
```
